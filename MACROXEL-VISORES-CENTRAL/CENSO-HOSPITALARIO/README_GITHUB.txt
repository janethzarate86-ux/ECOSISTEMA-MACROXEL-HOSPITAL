MACROXEL · Censo Hospitalario

1. Sube esta carpeta completa a un repositorio de GitHub Pages con el nombre CENSO-HOSPITALARIO.
2. En el Sistema Principal, entra a Configuración > Ruta visores GitHub y pulsa “Verificar visores”.
3. El visor se asociará automáticamente al Sistema Principal y a su Firebase activa.
4. Cada entrega admite máximo 3 archivos. Primero se genera la vista previa y después se pulsa “Validar y entregar”.
5. El visor envía a Firebase los datos estructurados extraídos; no almacena el archivo binario original.

Versión de integración: 1.0.2
