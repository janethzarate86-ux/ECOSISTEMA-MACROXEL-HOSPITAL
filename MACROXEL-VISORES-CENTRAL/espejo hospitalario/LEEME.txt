Esta carpeta usa la misma interfaz base del Sistema Principal y funciona únicamente como visor de consulta.

CONFIGURACIÓN
- No tiene cuenta GitHub fija.
- No tiene Firebase operativa fija.
- Recibe dinámicamente mxDb y mxSystem desde el Sistema Principal.
- La URL enviada por el Principal tiene prioridad y actualiza la asociación local de ese navegador.
- La Firebase de licencias y la Firebase de control están excluidas como bases operativas.

AISLAMIENTO
- IndexedDB propio: macroxel_hospital_mirror_db_v1.
- Configuración Firebase local propia del espejo; no comparte las claves del Principal web.
- Las escrituras del runtime hacia la Firebase operativa se neutralizan.
- La interfaz conserva el diseño del Principal, pero las acciones de alta/edición/eliminación quedan bloqueadas.
